# src/features/ one folder per screen or flow, default export used by `App.tsx`
- `auth/Welcome.tsx` first screen for signed-out users: create account / sign in, remember me, no credential prefill, guest link.
- `onboarding/Setup.tsx` year, subjects, exam dates (once). `onboarding/Tutorial.tsx` 6-step tour (also replayed from Help).
- `home/Home.tsx` hero mission + today's plan + exam countdown. Exports `KIND` (mission colour/icon/route).
- `session/Session.tsx` full-screen card review (new cards show the answer first): confidence 1-5, reveal, rate with interval previews, keyboard 1-5/Space/1-4. Again re-queues the card.
- `run/MissionRun.tsx` (shows the specific topic and a check-against panel from the organiser or notes) Brain Dump (names the topic; photo or typed dump is checked for missing points), Prove It (90 s timer), Past paper: brief -> work -> record -> logs via `actions.logMission`.
- `study/Study.tsx` Study tab: one numbered course list per subject in school order (reorder with arrows, "We're up to here" marks everything before it covered) -> key points, a step-by-step lesson with check questions (`content/lessons/`), "how well do you know it" self-rating (feeds the fog map), "Where are you in class?" paste box (auto-detects covered topics), links, "Learn from your notes" (import a notes PDF -> read on device -> step-by-step lesson), knowledge organiser (paste text, link, or file kept on device -> flashcards), deck player (free practice). Opens from Home via `/study?s=&t=`.
- `mock/MockExam.tsx` timed mock: setup (real paper lengths; attach the question paper and mark scheme PDF, kept on device) -> countdown on the wall clock (survives refresh) -> mark by question and topic -> result; weak topics update `topicKnow`. Logs a `paper` mission.
- `mock/PaperViewer.tsx` embeds an attached paper or mark scheme (blob URL in an iframe, with an open-full-screen fallback). Paper beside the clock; mark scheme beside the marking table.
- `progress/Progress.tsx` retention headline, trend, 14-day chart, per-subject bars, fog map, confidence vs result, exam readiness, paper marks. `progress/stats.ts` weekly retention (tested).
- `settings/Settings.tsx` account, sound, my cards, theme, subjects + exam dates, resources incl. student-added links.
- `help/Help.tsx` guide, FAQ, install tips, shortcuts; replay tour. Text lives in `content/guide.ts`.
